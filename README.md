# You Chose This

A level-based interactive word-selection installation and an experiment in what people value in life the most.


## What it is
You Chose This turns a participant's instinctive choices into a generative artwork. A field of words appears on screen across five levels starting from simple pleasures to deeply personal memories. Nothing is scored or judged: the system silently tracks what you chose and how fast you chose it, using reaction time to shape hidden watercolor blooms. The full artwork is revealed at the end, built entirely from the participant's own instincts.

## Stack

- Raspberry Pi 5 + Arduino Uno + joystick (KY-023)
- Node.js / WebSockets for the signal pipeline
- HTML5 Canvas for the interface and generative layer
